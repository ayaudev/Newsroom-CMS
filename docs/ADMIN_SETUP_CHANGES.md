# Изменения: первоначальная настройка и авторизация

Изменён существующий Newsroom CMS. React, Express, PostgreSQL, публичные API и функции публикаций сохранены. Рабочая база не использовалась при проверках. Зависимости не добавлялись. Лицензии и обязательные уведомления сторонних пакетов не изменялись.

## Проверки

Итог: 6 модульных тестов и 3 интеграционных сценария прошли; production-сборка frontend и git diff --check завершились успешно. Поиск старого названия и ссылки вернул 0 совпадений.

- npm test: валидация, TTY-ввод, отмена и безопасный HTML. Интеграционные сценарии при этой команде пропускаются по назначению.
- npm run test:integration: настоящий временный кластер PostgreSQL 18 на loopback; создание администратора через интерактивный TTY-стенд, успешный вход, запрет анонимного доступа (401), запрет роли user (403) на всех административных маршрутах, проверка подписи и срока JWT, запрет подмены роли, отказ повторного setup, конкурентное создание и отказ занятой почты. Успешный logout делает токен непригодным; второй вход остаётся действующим.
- Старые интеграционные сценарии проверяют публикацию/черновики, категории, модерацию, ответы, лайки, избранное, профиль, загрузку изображений и импорт MongoDB.
- npm run build: production-сборка существующего React-приложения.
- Поиск прежнего названия и прежней ссылки проведён по исходникам, конфигурации, документации и сборке, без каталога .git и сторонних зависимостей. Совпадений не найдено.

Новая схема применяется командой npm run migrate. Тесты создают только отдельные временные базы и останавливают кластер. Они не удаляют рабочие данные. Логин и права проверены через HTTP API; скрытый ввод проверен в TTY-стенде. Скриншоты страниц не проверялись: подключённый браузер в данной среде недоступен.

## Локальные команды

Из корня проекта (PowerShell):

~~~powershell
if (-not (Test-Path backend/.env)) { Copy-Item backend/.env.example backend/.env }
# Отредактируйте backend/.env: DATABASE_URL и JWT_SECRET.
cd backend
npm ci
npm run migrate
npm run setup:admin
npm run dev
~~~

Если администратор уже есть, setup:admin завершится отказом; войдите существующим аккаунтом и пропустите этот шаг. Нового парольного значения по умолчанию нет.

В отдельном терминале из корня:

~~~powershell
cd frontend
npm ci
npm run dev
~~~

Проверки из корня:

~~~powershell
cd backend
npm test
npm run test:integration
cd ../frontend
npm run build
~~~

Для другой установки PostgreSQL перед интеграционными тестами задайте POSTGRES_BIN, например:

~~~powershell
$env:POSTGRES_BIN = 'C:\Program Files\PostgreSQL\18\bin'
~~~
